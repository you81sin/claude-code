# 絵を描く（お絵描き活動）

pon が「**線を一本ずつ・毎回同じタッチ・手描き感**」で絵を描く活動。
追加インストール不要・無料で動く（既定で Pollinations.ai を使う。APIキー不要）。

## 使い方

```
python main.py pon
> /draw            ← pon が勝手にお題を決めて描く
> /draw ドラゴン    ← お題を指定
「ねこ描いて」      ← コメントからお題を拾う
```

## 仕組み（“AIっぽい完成画像”を出さない）

```
お題を決める（指定 / コメント抽出 / ランダム）
   ↓
線画を生成   drivers/image/novelai.py（seed固定＝絵柄を寄せる・白地に黒線）
   ↓
線に分解     libs/sketch.py（画像→連続した線＝ストローク列）
   ↓
手描き化     線に微小な手ブレを足す（humanize）
   ↓
保存         apps/pon/data/draw_strokes.json（線データ）
   ↓
1本ずつ描画   apps/pon/draw_viewer.html が固定ペンでアニメ描画
   ↓
感想を一言    既存の音声経路で喋る
```

### 3つの要件をどう満たしているか

| 要件 | 実装 |
|---|---|
| **線を一本ずつ** | 画像をストローク（線）に分解し、ビューアが1本ずつ順番に描く |
| **毎回同じタッチ** | 最終的な見た目は pon 専用の**固定ペン**（色 `#2b2b2b`・太さ一定）で決まる。元画像の絵柄がブレても仕上がりは毎回同じタッチ。さらに生成 seed も固定 |
| **AIらしさ < 人間らしさ** | 線を少し揺らす／人が描く順（左上→右下・形から）／描く速度を揺らす／線と線の間でひと呼吸（たまに長考）／鉛筆っぽい入り抜き |

## 配信で見せる（OBS）

1. OBS に「**ブラウザソース**」を追加。
2. ローカルファイル `apps/pon/draw_viewer.html` を指定（または簡易Webサーバで配信）。
3. `/draw` するたび `data/draw_strokes.json` が更新され、ビューアが自動で描き直す。

> 元画像そのものを見せたい場合は `apps/pon/data/current_drawing.png` を画像ソースにしてもよい。

## 線モードに必要なもの（任意）

- 画像→線の分解には **Pillow** が必要：`pip install Pillow`
  - 無い場合は線分解をスキップし、元画像表示のみになる（落ちない）。
- 画質を上げたいなら `.env` に `NOVELAI_TOKEN` / `SEGMIND_API_KEY`（任意）。

## タッチを変えたい

`libs/sketch.py` の `DEFAULT_PEN`（色・太さ・手ブレ量・描く速さ）を調整する。
ここを固定している限り「毎回同じタッチ」は保たれる。

## メモ

- pon は IQ15〜30 のポンコツ設定なので、線画も「下手かわいい・素朴」方向に寄せている。
- 検証: `python tools/test_drawing.py`（画像生成はモック・線分解の中核は実テスト・ネット不要）
